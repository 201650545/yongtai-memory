## 跟读验收一直识别不出：根因已定位并修掉（2026-10-15）

**症状**：小米14 真机，孩子读对整句 → ASR 只吐 ~1 个音节，分数 0.04~0.09。

**两个根因，前一个已修、后一个是本次真凶：**

1. **采样率（2026-10-13 已修）**：安卓 `AudioRecord` 只把请求的 sampleRate 当建议，
   小米14 原生交付 48000。此前请求 16k ＝ 16k 头 + 48k 身，声音被拉慢 3 倍。
   修法：明确请求 48000 + `PcmDecimator` 抽到 16k。

2. **BBPE 字节片（本次真凶）**：中文手机主力档
   `sherpa-onnx-zipformer-ctc-small-zh-int8-2025-07-16` 的 `tokens.txt` 是
   **1000 个 BBPE 字节片**（`▁ƌŕş` 之类，0 个 CJK）。**`result.tokens` 恒为
   这些原始字节片，只有 `result.text` 是正确中文。** PC 实测四种
   modeling_unit / bpe_vocab 组合（`''` / `cjkchar` / `bpe` / `bpe+bbpe.model`）
   **结果完全一致** —— 即 BBPE 合并只在 sherpa-onnx 产出 `text` 那一步发生，
   `tokens` 数组不回写解码结果。
   ⇒ **之前怀疑的「缺 bbpe.model / 没设 modelingUnit=bpe」是错的**，加不加都一样，
   该文件根本不参与本档解码。

   **修法**：`sherpa_onnx_asr_engine.dart` 里 BBPE 档改走 `result.text`
   （`_charsOf` 拆字符 + `_resampleTimestamps` 把时间戳线性重采样到等长），
   下游 `tokensToWords`／接缝逻辑完全不必知道 BBPE 存在。
   档位标志 `AsrTier.tokensAreByteLevelBpe`（只有 zhSmall 为 true）。

**真机验证（小米14，模型自带 test_wavs/0.wav）**：
`rawJoined="▁ƌŕş▁ƍĩĴ…"`（仍是乱码）→ `text="对我做了介绍那么我想说的是呢大家如果对我的研究感兴趣呢"`
→ `joined` 同上、`HAS_CJK=true`。

**回归**：`flutter test` **862 全过**；`flutter analyze` **0 error 0 warning**
（26 条是 `tool/` 下既有 avoid_print info，属红线目录未动）。

**可复用的判据**：sherpa-onnx 里 **`result.text` 才是文本真源**，
`result.tokens` 对 BBPE 档只是字节片——任何拼 tokens 的管线都会得到乱码。
以后换 BBPE 模型先查 `tokens.txt` 有没有 CJK。

## 🔴 跟读验收形态重构（2026-10-16 郭老师拍板，5 个 commit）

**产品目的（郭老师亲口定）**：学生学完课文一句一句过，**每句里每个字都要读准**；哪个字没读准就重点练那个字，多读两遍；全读准了才进下一句。核心是"每个字的音都对"，不是流利度、不是跟原声一样。**这句话里没有分数、没有满星。**

**形态**：整页（不是弹窗）。五个画面：该读了（课文大字居中）→ 正在读（**双行实时红绿**：上排要读的字，下排实时识别出的字，对绿错红）→ 读准了（「这几个字都读准了」页面正中 + 下一句）→ 没读准（**自动**把红字单拎出来放大居中 + 自动播标准发音 + 自动开录，读准自动收队，错字全练完自动重放原声读整句）→ 没听清（不计失败）。

**三条拍板**：① 单字练习**管声调**（整句仍比音不比字，秋/球算对；单字 qiú≠qiū）② 单字练习**不卡次数** ③ 整句重读**最多两轮**，超过放过去。

**撤掉的**：大号分数、满星、第 N 次、跳过这句、看错在哪折叠、逐字/拼音对照行、语音纠错播报、「这几个字再练一下」中间屏。**「边读边显示」撤了又请回来但换了判断标准**——原来显示"app 听到了什么"（识别常错，滚出来是错字反而带偏），现在显示"跟课文对上了几个字"。

**为什么砍（有数据）**：课件原声 7 句喂给同款识别模型，4 句全对、3 句错，且两个方向：两句**假失败**（漏字 0.879、丢半句 0.478，正确朗读被罚）、一句**假放行**（秋→秧 0.871，6 音节正好命中短句豁免，读错的音给过了）。假放行比假失败更阴险——孩子读错一个音，满分通过还给他正反馈。
