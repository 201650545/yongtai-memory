# ffmpeg 烧字幕的「静默失败」：四层叠加

**核心词**：滤镜没挂 / 每图只 1 帧 / 锚点偏移 / stderr 死锁 / showinfo 数帧

**踩过的现场**（2026-10-21 · video-assembler v3 四轨渲染）：
课文成片 **一条字幕都没有**，但 ffmpeg 退出码 0、日志零告警、report 还写着 `subtitles_burned: true`。
修了四层才出片——**每一层单独都能让字幕消失，且互相掩护**。

**结论（已验证）**

1. **挂滤镜的代码不能写在调试开关分支里**。
   `if os.environ.get("VA_KEEP_ASS"): … vf += ",ass=…"` ⇒ 正式渲染滤镜链里根本没有 ass。
   成功判据也不能是"文件存在"，要是「**滤镜真挂上了 ＋ ffmpeg 成功**」。
2. **「PNG ＋ duration」的 concat 列表，每张图只产生 1 帧**。
   `showinfo` 实测整片只有 **3 帧**（pts=0 / 4.04 / 15）——`duration` 只推进 PTS、不生成中间帧。
   ⇒ 字幕滤镜只采样 3 个时间点，事件区间稍晚就**一条都画不出**；
   而输出端 `-r 30 -fps_mode cfr` 把 3 帧拉成 4815 帧 ⇒ **画面看着完全正常**，极具欺骗性。
   改法：每张图先编成**真帧流短片**（`-loop 1 -frames:v N`）再 concat（与音频侧同套路）。
3. **ASS 绘图 `\pos(x,y)` 的锚点跟随样式的 `Alignment`**。
   样式是底边居中(2) 时整框偏 `(-w/2,-h)`（实测期望 464,119 → 画在 436,66）⇒ 绘图要显式 **`\an7`**。
   顺带：**`\alpha&H30&` 是 81% 不透明**（不是 30%）——要浅色高亮框得用更大的 alpha（如 `&HA6&`）。
4. **ffmpeg 的 stderr 走 PIPE 且超过 64KB ⇒ 死锁**。
   症状：ffmpeg 进程在、**CPU=0**、输出文件 0KB、脚本永不返回 ⇒ 父进程轮询等退出等不到。
   改法：**stderr 落文件**（`-loglevel info` 一次就写几百 KB，必现）。

**排查顺序（照这个走，别乱试）**
① 打印渲染 CMD，看滤镜链有没有 `ass=` → ② `showinfo` 数帧数、看 `pts_time`
→ ③ 用脚本量色块 bbox 与目标坐标对账（**别靠肉眼估偏移**）→ ④ 最后抽帧目测（内容对错只有眼睛能判）。

**第 5 层（追补）：人改了字幕，产物却没变**
审片界面改一句字幕（`cue.text`）后重渲，成片还是老样子——
因为渲染取的是 **token 的字**（`{\kf…}t["ch"]`），`cue.text` 只是个给人看的字段。
⇒ 「AI 自动剪 → 人可复核可纠正」这条链在最后一厘米断了。
**修法**：等长改字 ⇒ **逐位贴回 token**（卡拉OK 分段与逐字高亮仍同源）；
不等长 ⇒ 退化成整句普通字幕（该句失去逐字高亮，但文案正确）。
**纪律**：同一个语义字段只留一个真源，但**"人改的"必须能覆盖"机器算的"**；
验收必须**改一个字 → 渲染 → 抽帧看**，只测「接口返回 ok」测不出这种断链。

**第 6 层（追补）：预览渲染**原地覆盖成品** ⇒ 正在播的片子当场黑屏**
审片界面点「重渲（低清快验）」，预览路径只改了**内存里**的 `output.path`（没落盘），
而调用渲染时**没传 `--out`** ⇒ 渲染器按工程文件里的路径写 ⇒ **低清预览写进了正式成品的位置**。
**规律**：① 凡是会写产物路径的调用，**必须显式传输出路径**，别依赖默认值（默认值会被人改掉）；
② 预览产物必须落独立文件名、**永不与正式产物同名**；
③ 改了默认值但没落盘 ⇒「我改了」和「它变了」是两件事；
④ 验收＝**记下成品 (size,mtime) → 触发预览渲染 → 再比一次**，不变才算修好。

**配套纪律**
- `-loglevel` 默认用 `warning` 不用 `error`：libass 的字体/字形告警在 warning 级，压在 error 级**一个字都不报**。
- **机器判据不可信**：`signalstats` 量亮度判「有没有字幕」时，页面正文/注释本身就把亮度拉低
  （实测无字幕 231、有字幕 213），阈值定松会把「没有字幕」判成「有字幕」——这次差点被带偏。
- **修好位置后要一起定样式**：位置一准，原来 81% 不透明的实心红就**正好盖住被读的字**。
  实测三方案：实心（字全遮）／浅填充 `&HA6&`（字可读，**采用**）／只描边
  （**libass 对 `\p1` 多边形不描边 ⇒ 画不出来，不可行**）。
  颜色/透明度/描边做成工程旋钮（`highlight_color`/`highlight_alpha`/`highlight_border`）。
