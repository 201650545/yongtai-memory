# A4 教辅排版：每页一样 + 不留空白 + 不留孤字（2026-10-21 实测）

## 症状（郭老师看图指出的）

「每个空间空这么多，又不对称，又没有什么规律，每一页都这样；有些地方换行之后只有一个字。」

实测（浏览器量，不是目测）：

| 指标 | 改前 | 改后 |
|:--|:--|:--|
| 每页词数 | 4.3（4/5/6 混着来） | **6，每页都一样**（末页 4） |
| 页面利用率 | 32%—95.9% 乱跳 | **一律 99.6%** |
| 卡片高度 | 228—343px 不齐 | **一律 272px** |
| 断行孤字（末行剩 1—2 字） | **304 处** | **81 处** |
| 溢出 / 压字 | — | 0 / 0 |

## 三个可复制的做法

### 1. 固定网格 + 锁行高 ⇒ 每页长得一样

```css
.ecgrid{display:grid;grid-template-columns:88mm 88mm;column-gap:6mm;row-gap:2.2mm;
  grid-auto-rows:minmax(0,1fr);align-content:stretch;height:calc(100% - 10mm)}
```
- `minmax(0,1fr)` 而不是 `1fr`：**行高不许被内容顶大**，否则内容多的行把整页顶出内容区（实测溢出 46px）。
- `calc(100% - 10mm)` 给底部条（本册是「本页词表条」）留位，别让卡片压上去。
- 卡内用 `justify-content:space-between`：卡高固定、**空隙变有节奏的行距**，而不是底部一块白。
- ⚠️ 贪心分页（装不下就换页）会造出"4 词页/5 词页/6 词页"混排 ⇒ **改固定每页 N 个**，页数由 N 决定。

### 2. `text-wrap: pretty` ⇒ 引擎级防孤字

Chrome 153 支持 `text-wrap: pretty`（防末行孤字）与 `text-wrap: balance`（短块均分）。
散文块（用法/例句/变形/易错）用 `pretty`，短块（搭配格）用 `balance`。
**实测：孤字 304 → 81，且大部分不需要动字号。**

### 3. 浏览器实测的自动缩排（兜底）

`document.execCommand` 缩不动 ⇒ 要**连块内显式字号的子元素一起缩**（如搭配格里的 9.5pt 释义），
否则"缩了等于没缩"。顺序：
1. 先收 `letter-spacing`（保持字号不动）；
2. 再**等比**缩字号（比例 0.98→0.93，即 10pt→9.3pt）；
3. 还超 ⇒ 按原型收内容（**「变形」里那句例句与第 5 层例句重复，可去**；「同类」原型就是 2 项）；
4. 最后兜底循环：只要有元素越出卡边界就再缩一点（**压字＝静默裁切，必须 0**）。
改完把 DOM 序列化落盘，**PDF 与 HTML 用同一份**，别让两次渲染不一致。

## 顺带查出来的内容硬伤

看渲染图时发现卡片上印着 `get one's ◎[美国口语]得到应…` —— 母表 `collocation` 列里混着
**词典残句**。处置：清洗（丢带 `◎`/`[美]`/尾部截断 `...` 的条目）+ **硬门**
（渲染后扫全文，出现词典标记就报错，防它再混进来）。

## 通用检查项（做成脚本，别靠眼睛）

`06_templates\_audit_layout.py`（利用率/卡高/每页词数）、
`_audit_dangles.py`（逐字符分行数，抓孤字）、
`_find_clip.py`（谁越出了卡边界）。
⚠️ 逐字符分行要**按 top 容差 3px 聚类**：行内小标签是 inline-block，top 会差 1—2px，
不带容差会把标签那 2 个字误判成孤字（2026-10-21 误报过 300 多处）。
