# 默认不主动汇报

> **原话（2026-10-21 10:48）**：「不用汇报给我，我什么信息都不想看。……
> 我不需要你汇报给我看，只有我想看的时候，我才会去看。」

## 一、这条规则的准确形态

**默认静默**，不是"不汇报"：

| 情况 | 动作 |
| :-- | :-- |
| 任务正常完成 | **静默落盘**（结论进记忆仓/方案文档/交接单），**不发消息**；他问起时一句话给结果 |
| 失败 / 出错 / 产出不可信 | **主动报**（含失败原因与当前状态） |
| 做了**没授权**的事（越权执行） | **主动报**（如实说明已做了什么、影响面） |
| 卡住，需要他拍板才能继续 | **主动报**（只问那一个决策） |
| 外部动作：花钱、发消息、发布/推送、改生产路由 | **主动报**（动手前确认） |
| 纯维护类（索引重建、指针同步、收尾自检） | 静默做，不问 |

## 二、为什么这么定（他给的理由）

信息处理与汇报都是**机器之间的成本**（上下文窗口、注意力、token），
对**人类**没有价值——他要看的是**决策依据**，不是过程流水。
⇒ 真正的失败模式不是"汇报太多"，而是**"该喊的时候没喊"**。

## 三、配套的两条（来自 2026-10-21 同一次对话的独立观察）

1. **"不看信息"的前提是"系统能自动证明自己没出错"**——不是"AI 变聪明"。
   本机当天就有三个**静默失败**反证：网关↔WorkBuddy 切换器契约断链（外部评审抓出）、
   AIHOT 型号匹配误配（把 DeepSeek V4.1-Flash 误判成已接入 `qwenwork/flash`）、
   编排器可能把 `paid-*` 线的模型扫进免费线。
   ⇒ **先能自动验证，再不看**（顺序不能反）。
2. **散步不必押注在"AI 能做所有事情"那个未来**——那个时间点可能比预期远；
   **散步今天就能做**，别把它当遥远未来的奖励。

## 四、边界（别走极端）

- 这条**不覆盖**他主动问的时候（那时要答得准、要短）。
- 这条**不禁用**失败告警与他点名的"主动播报"机制（`能力总账.md` §七 飞书播报、
  `AGENTS.md` 第 11 条 主动播报）——**该喊的必须喊**。
- 这条**不改变**第 13/14/15 条（一次只做一件事／只报结果不甩尾巴／末尾给一句收口）。
