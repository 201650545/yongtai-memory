# 封面配色必须与内页统一

## 他的原话（2026-10-21 17:2x）

> 「还有一点，要保持配色统一，封面跟正文没有统一。
> 比如你做的那个"688字四列紧凑速查"，封面做的是蓝色调，但是里面是红色的。」

## 为什么会跑偏

我按"同系列三本换三种主色"的思路做封面（朱红 / 靛蓝 / 橄榄绿），
**这套逻辑是错的**——它追求的是"三本看起来像一套"，但**没跟各册内页的实际用色对齐**。
⇒ 结果：② 封面靛蓝、内页红；①② 封面米黄底、内页白底。
⇒ **"统一"有两个维度：同系列之间统一（版式骨架）＋ 封面与本册内页统一（配色）**，两个都要，缺一不可。

## 实测内页主色（2026-10-21，像素统计）

工具：`_analyze_inner_colors.py`（抽内页 PNG，算高饱和像素的色相分布 + 具体色 Top）
⚠️ 别靠肉眼扫，得**抽样统计**，否则会漏掉"大面积留白 + 少量彩色"的内页。

| 册子 | 内页视觉 | 主色 | 封面应取 |
| :--- | :--- | :--- | :--- |
| ① 核心82词深度词条册 | 白底 / **黄色高亮词头** / 淡蓝标签 / 朱红易错 | **黄**（+淡蓝辅） | 黄底黑字块 + 朱红徽标 |
| ② 688词4列速查成册版 | 白底 / **红色词条标号** / 红标题 / 红"湖南专版"角标 | **红** | 红（主色）+ 白底 |
| ③ 易混词辨析册 | 白底 / **黄色组标题条** / 黄粉蓝红四色小标签 | **黄** | 黄底黑字块 |

**底色统一改白底**（内页全是白底，封面用米黄纸底也是不统一）。

## 关键细节：黄色不能当文字色

白底上写黄色字 = 看不见。内页的黄色用法是**底色块 + 黑字**（`#ffe95c` 底 + `#1f2430` 字），
不是黄色文字 ⇒ 封面照抄这个用法：`.tt em{color:黑; background:黄}`。
同理 **红色内页是文字色**（无底）⇒ 封面用**红底白字块**呼应，徽标也用红。

## 插画也要跟着配色走

② 原插画是**蓝调图书室**，跟红色内页打架 ⇒ 重新生图时提示词里写死
`WARM RED AND CREAM AND BROWN color palette, muted brick red book covers`。
⇒ **配色统一不只改色块，插画本身的色温也要对上。**
