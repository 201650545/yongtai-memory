# 一次只做一件事，按顺序推进

## 他的原话（逐字）

> 「按顺序一个一个来吧，记住这一点，我每次只能按顺序一个任务一个任务地来」（2026-10-20 21:56）

## 含义

- **同一时刻只推进一条**。做完 → 报 → **停下等他点下一条编号**。
- **不许打包**：我提议过"要不要同时做 A 和 B"时，他明确拒绝——按顺序来。
- **不许自作主张升级**：依赖项（如 IDEA-022 的转译标准）如果当前这条需要它，**先把依赖说清楚并请他定**，
  顺手把依赖项也做掉＝越界；除非他点头把它并进本条。
- **顺序不是我重排的**：想法池 `§5 读出规矩` 已经定了报法（① 已指派未完成 ② 中期 ③ 远期与常驻 ④ §4 已废弃项），
  照那个顺序报，别自己按"好不好做"重排。

## 边界

- 这次说的"一次一个"指的是**他派的任务**（想法池条目 / 编号指派）。
  **纯维护类**（索引重建、指针同步、收尾自检、经验草稿落盘）不算"任务"，该做就做，不用等他点。
- 他这句话不改变"只读研究可以自己做"的规矩（想法池 §7 硬规矩 3），但研究做完**仍记 captured**，
  别把研究结果直接升级成任务。
