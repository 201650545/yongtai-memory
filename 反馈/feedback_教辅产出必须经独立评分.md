# 教辅产出必须经独立评分（2026-10-24 09:15 郭老师）

**原话**：
> 「加入一个评分与优化机制。每次产出产物之后，主模型需要制定评分标准与细则。
> ① 制定标准：根据学生的学情、年龄特点，以及官方对学生学习的要求与规范，为设计的练习与资料制定评分标准与细则。
> ② 独立评分：在子 Agent 产出产物时，必须由专门的『评分子 Agent』进行评分。为了避免作弊，做事情的 Agent 和评分的 Agent 不能是同一个。
> ③ 优化机制：以满分 10 分为例，8 分算合格。如果子 Agent 的评分未达 8 分，则需要重新制作优化。」

**Why**：内容对 ≠ 能用；这一条是给教辅产品线加的一道质量闸。制作与评分分离，是为了防"自己给自己打高分"；分数线是为了让"做完"不等于"能交"。

**How to apply**：
1. 主模型定细则（六件事写全：维度权重／判定口径／取证方式／核验状态／扣分规则／合格线），**细则先落盘**。
2. 评分子 Agent 必须是**没参与制作**的新 Agent，只读，给可核扣分证据。
3. <8.0 返工，返工后再评；上限 2 轮，仍不达标报给郭老师。
4. 细则的三个依据：学生学情、年龄特点、官方要求与规范。

（AI 提交 1：2026-10-24 09:3x 郭老师补充原话——「加入教师评分机制之后，你做完内容一定要审核准确性和合理性，然后再进行评分。评分不合格就要优化，以达到评分要求。打分的是和产出不一样，要记住了。评分的 Agent 和产出的 Agent 不一样。」
**口径补充**：回路从三步变四步——**产出 → 内容审核（准确性与合理性）→ 评分（10 分制，≥8 合格）→ 不合格则优化重做**。审核 Agent 与评分 Agent 都必须不是产出 Agent；四个角色（产出／审核／评分／返工）互不重叠。
