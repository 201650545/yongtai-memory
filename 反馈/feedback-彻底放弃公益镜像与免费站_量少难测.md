# 彻底放弃第三方公益镜像站与免费共享站（2026-11-04）

> **规则**：严禁调研、接入或留存任何第三方公益镜像站、免费共享席位（如 48Team/CPA）、论坛羊毛中转站或未审计的公共代理池；已全量物理删除相关记忆，后续绝不再做此类尝试。

**Why（郭老师原话与判据）**：
1. **量少且无法用于批量测试**：郭老师明确指出「量少，不好做批量测试」。共享池额度随时撞墙（429/503），在批量任务或自动化流水线中会频繁中断，毫无工业可用性。
2. **极不稳定且拖死主业务**：别人运维的池子随时停服、清零或收紧权限，挂在回落链上只会增加前置错误延迟。
3. **数据安全风险**：公共未经审计的代理中转存在 Prompt 泄露与二次中间人拦截风险。

**How to apply（如何执行）**：
1. **渠道准入只认官方与自有账号**：模型与 API 接入严格限定于①官方付费订阅/API、②官方商业直签、③大厂稳定官方 Free Tier（如 Google AI Studio 等自有账号凭据）；其余任何“网友共享/公益免费/接码羊毛”一律直接否决。
2. **拒绝此类调研提案**：在规划算力与网关供给时，绝不提出“去外部搜刮免费中转站/公益站”的方案，不浪费上下文与测试精力。
