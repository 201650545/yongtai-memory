# 收尾不是回答完就完：三写＋实测

## 一、三写义务（缺一不算收尾）

| 写什么 | 写到哪 | 判据 |
|---|---|---|
| 本轮流水（动了哪些项目、数字、我自己的口径纠正、留给下一任的未决项） | `D:\Work\项目索引\rounds\YYYY-MM-DD.md` | 文件里能出现本轮的数字与产物路径 |
| 跨 Agent 要复用的事实/决策/教训 | `D:\记忆\调度大脑记忆\` 对应分类文件夹（反馈/项目/流程/教训/参考/用户） | **必须在 `索引.md` 挂链**，否则等于没写（索引是唯一的发现入口） |
| L1 经验条目（踩坑突破、纠偏） | `D:\Work\元智能\10_AI自成长引擎\草稿区\L1_经验\` | 静默落盘，不当面炫耀 |

（2026-10-01 修：原写 `D:\Work\AI自成长引擎\草稿区\L1_经验\`，该目录随元智能重组已不存在，每轮收尾都会撞死路径。）

**只写 rounds 不写本库＝下一任 Agent 读不到**（rounds 是流水，本库才是跨 Agent 的机制与偏好真源）。2026-09-30 自查：本轮网关修复一开始只落了 rounds，本库 0 条。

## 二、"到位"的判据是实测，不是文档

郭老师反复用同一句话打回：**"我之前说过 / 不是有做过吗"**。含义＝他验收的是**机制跑到的等级**，不是"有没有写过这条"。

- 例（2026-09-30）：他要"交互卡片判决＋自监督脚本每 5 分钟巡查＋审完自动保存转到规定路径"。写进规范文档不算到位；必须实测到：自动交卷触发、巡查命中、自动 dry-run、dry-run→一个字→四处真删→终检全绿，才算那条机制"活了"。
- 推论：交付时说"已生效"必须带**同批次时间戳的运行见证**（日志行、产物字节、进程 PID＋启动时间），否则他会问"到位了吗"，而那次问的是能不能证伪。

## 三、他拍板时回一个字就够

需要他裁定的事项（加席/删席/改名/重启这类共享状态动作），把实质后果翻成白话＋给出默认动作，让他回"改/不改/先不动"。技术 A/B 决策优先转镜像 GPT 裁定，不把选择题丢回给他（见 [[调度大脑记忆/反馈/feedback-stop-nagging-route-to-gpt]]）。

## 四、数字与路径落盘前先自校

- 引用即校验：路径 `Test-Path`，数值跨真源比对；本轮踩到 `route_log.jsonl` 的 `ts` 只有时分秒（无日期），按字符串切窗口把**昨天**的行圈进"今天改后窗口"，第一版对照作废重算（改用字节偏移）。
- 子代理/别会话的自报不是证据：引句做子串核对、产物做磁盘核查、数字重算。
