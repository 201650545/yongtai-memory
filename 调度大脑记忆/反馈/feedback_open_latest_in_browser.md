# 做完就直接在浏览器打开最新的

郭老师 2026-10-10 原话：「你每次做完直接把最新的在浏览器打开」。

**适用**：任何"做给他看/给他用"的网页类产物——判决台、看板、HTML 页面、可视化。
**动作**：生成/更新完成后立刻 `Start-Process` 打开，不等他问"在哪看"，不让他手动翻目录或按 F5。
**防旧缓存**：同一路径的 file:// 页面，已开着的标签页不会自动重载。
打开时带一个一次性查询参数（`?v=时间戳`）强制新载，杜绝"我明明更新了他看的还是旧的"。

**Why**：他视角里"做完"和"看到"应该是一件事；让他自己刷新/找文件是无谓摩擦。
