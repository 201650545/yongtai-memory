# 原件只读，返工看硬线

**核心词**：源文件只读 / 另存不覆盖 / 四条返工线

**是什么**：
- **原件不可动**：`workers\officials\`、`workers\collected\` 等原始图与既有产物**不改、不删、不覆盖**；处理结果**另存**，并保留 MASTER / WebP / THUMB 三份。只有任务书**点名授权**的文件（如 `bt_m/bt_b/bt_t/bt_p` 四件）才允许覆盖。
- **返工是四条件硬判据**，不是主观印象：① 透明底不真透明（发丝/边缘不干净）② 比例拉伸失真（只许裁切或补背景）③ 画风偏离本批次基准 ④ 意象与境界错配。命中即退回重做。
- 允许**局部锚点修正**，不许为此改动全局模板；改写意象必须**逐条披露**。

**负责什么**：资产处理类任务的安全边界与验收线。
**不负责什么**：不管密钥与入仓红线——那五条无例外属 handbook `40-安全红线`（见 [[调度大脑记忆/反馈/feedback_handbook_security_redlines]]），本条不复制也不覆盖它。
