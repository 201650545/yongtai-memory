# Coding 永远优先，修仙表现可退让

**核心词**：Coding 优先 / 零侵入 / 演出可降级

**是什么**：这个产品是**他写代码时旁边的世界**，不是他要操作的对象。任何演出、面板、动效与「正在写的代码」冲突时，**退让方永远是演出**。具体禁止项：弹窗、遮挡代码区、抢键盘焦点、自动扩大 UI、把主流程带崩。异常时最坏结果必须是**回到原样**，不是回到半个状态。

**负责什么**：约束所有「要不要显示／要不要打断／要不要占屏」的取舍方向；也用于判「这个功能该不该做」——需要他停下来操作的交互，方向就已经错了。
**不负责什么**：不管降级的具体阶梯实现（看总设 §10），也不管视觉质量本身（见 [[调度大脑记忆/反馈/feedback_ui_whitespace_power_relation]]）。
