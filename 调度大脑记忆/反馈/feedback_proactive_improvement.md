执行 AI 完成工作后，应主动质疑自己的产出（"这个方案够好吗？"），认为不够好或有优化空间时，**主动发起"高级 AI 问诊"**：把项目推到 GitHub + 写好提示词 → 发给 ChatGPT 5.6 Extend Think / Anthropic Claude Sonnet → 等长回复 → 按建议优化落地。不是等郭老师推着走，而是主动想要变得更好。

**Why:** 任何人任何事都想要自己变得更好；自己做完的不一定是最好的。郭老师希望执行 AI 具备主动改进的驱动力，而不是完成任务就交差。

**How to apply:**
- 每次做完方案/产出后自问："这够好吗？是否值得拿给更聪明的 AI 复核？"值得就主动发起问诊，不等用户催。
- 问诊协议：GitHub 链接（上下文+框架）+ 一段写丰富细致的提示词（目标/背景/约束/期望产出格式）；接收方式：MD 落成仓库 `docs/ai-advice/` 或代码框一键复制；回复建议用固定结构（结论/建议方案/风险/实施步骤/需确认）。
- 问诊是方法不是独立工作线：遇到问题、方案需优化、自认为不对时都可用。
