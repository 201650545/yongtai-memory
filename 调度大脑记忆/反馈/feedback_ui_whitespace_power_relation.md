# 留白归天地，不归信息

**核心词**：留白权力序 / 主界面不负责解释 / 禁手动切外观

**是什么**：他给的序是 `天地 > 王林 > 事件回响 > 信息`。派生出的判据一句话：**凡是必须阅读、比较、筛选才能理解的东西，都不许占留白**。因此——四窗是天地变化不是四个 Tab；双身是心境显化不是角色选择；Coding 行为是世界天气不是数据面板；破境是全局事件不是一个页面。

另一条独立的禁令：**外观/身份类状态不得长出手动切换开关**，已由「Coding 心境派生相位」取代，手动外观管理属**已废止**方案——不要在评审里把它当新想法提。

**负责什么**：新增任何界面元素时的归属判定（进留白？进二级页？还是不该存在）。
**不负责什么**：不管具体树结构与节点清单（那是原文 §6 的权威定稿），也不管视觉风格本身。
