# 内容可以扩，结构契约不可动

**核心词**：字段不许发明 / 无可靠信号宁可不触发 / 拿不准写未知

**是什么**：他把两件事分得很清——

1. **结构是定稿**：JSON 模板字段、境界 id、manifest 键名、阶段主题、Effect 白名单，执行方**一律不许改名、增删或自造**。发现结构有问题，唯一正确动作是**写进汇报请他决策**，不是就地改。
2. **事实要可溯源**：每条数据必须能指回章号或来源 URL（他会抽查）；**拿不准就写「未知」或留空，并登记进 `gaps`**；宁缺毋滥，禁止凑数。AI 扩展出来的内容在进事实源之前必须走核验流程；映射只能称「世界观映射」，不许声称原著因果。

**负责什么**：约束所有"执行 Agent 自作主张"的方向，包括改字段、补数据、把猜测写成结论。
**不负责什么**：不管文案的合理提炼与创作发挥（那是表现层，不是事实层）；具体字段清单以原文为准。

与「先证明再动手」是同一族纪律，别与 [[调度大脑记忆/反馈/feedback_ui_whitespace_power_relation]] 的界面归属判定混用。
