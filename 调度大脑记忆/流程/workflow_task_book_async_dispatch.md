# 任务书派工：只写指定路径，不联系主管

**核心词**：任务书 / 只写指定目录 / 幂等可续跑 / 汇报才算结束

**是什么**：他用「任务书」当派工接口，四件事是固定的：
1. **交付通道唯一**：产出文件与汇报**只写任务书点名的那几个路径**，除此之外**不在任何位置落盘**；主管自己来取，**执行方不主动联系主管**（所以不要求他等回复、不要求他发消息）。
2. **汇报是收尾条件**：`汇报写完才算任务结束`——没有汇报等于没做完。汇报里必须含**需主管决策事项**。
3. **脚本幂等可断点续跑**：批量生成类脚本必须能重跑而不重复劳动（配额、限流都是真实约束）。
4. **免费通道不许重试轰炸**（限流实测过，撞限流要靠退避不是靠循环）。

**负责什么**：任何"派给另一个 Agent 干活"的交接形态与验收定义。
**不负责什么**：不管**给谁看**——产物给 AI 看、只把待决策给他，这条是另一份记忆 [[调度大脑记忆/反馈/feedback_ai_face_no_read]]；也不管密钥与不入仓（handbook `40-安全红线`）。别把三者混成一条。
