# 挂不上主链就别开工

**核心词**：主链 / Parking Lot / WIP≤1 / 动词化任务名 / 更确定≠完成度

**是什么**：他判断"这件事现在做不做"用的是一条固定链路：**年 → 季 → Gate → 月 → 周 → 日**。一个任务如果三问皆否（帮不了当前 Gate／不是修复阻断／不降低维护风险），**进 Parking Lot，不直接开工**。

配套三条硬规矩：
1. **WIP≤1**：今日 ≤1 主任务 ＋ 2 小任务。
2. **任务名必须是动作**：要能回答"今晚我怎么知道做完了"。**"完善修仙系统／优化玩法／推进 A1" 这类他明令禁止**——那是方向不是任务。
3. **月度产物 = 原型＋证据＋决策**，目标写"到月底对某件事更确定"，**不写完成度百分比**；本周必须交付一个能运行能观察的**最小闭环**，并且要有**明确不做清单**。

**负责什么**：给他排任务、或替他判断某件事该不该现在动。也是自查节律的参照——他自己承认的毛病就是"建了大目标就一股脑执行、不拆小产品"（见 [[调度大脑记忆/用户/user_guo_three_identities]]）。
**不负责什么**：Parking Lot 的准入门题（"它解决哪个已观察到的具体问题"）属 handbook `60-开发者与管理者角色` §5.1，本条不复制；跨项目通用节律也以 handbook 为准。
