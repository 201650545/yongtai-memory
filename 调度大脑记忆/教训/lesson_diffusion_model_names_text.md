# 想让它别写字，就别提"能写字的东西"

**核心词**：无字红线 / 负面提示反效果 / 不点名可刻字物体

**踩过的现场**：27 境破境视频首轮产出有 6 境被模型画上了汉字。第一次修复**方向是错的**——在负面提示里点名「无文字石碑／无字墓碑」，结果 5 个重做视频里石碑**更多**且刻满中文。

**结论（已验证）**：扩散模型对可刻字物体的**名字**敏感，对否定词不敏感。
- 正面描述（"碑面光滑空白无刻字"）同样无效；
- **唯一有效写法是根本不点这类物体的名**。
按此改写后全量复检干净；结论已固化进 `gen_bt_batch.py` 的 `ANTI_TEXT` 注释，避免复用再踩。

**负责什么**：一切「要求画面里不出现可读文字／水印」的生成任务，包括图与视频。
**不负责什么**：不是"少出现字"而是零容忍；不禁 UI 层自己叠的判词（那不走生成）。也不外推到"负面提示一律无效"——本条只覆盖可刻字物体这一类。
