**所以规矩是**：想法一律落**这个文件**（在共享记忆仓，所有 Agent 都读得到），不落任何 Agent 的私有记忆。

## §7 三条硬规矩

1. **写之前先 grep 本文件**：他反复重述同一件事是常态，命中就**更新那条**（加一行"YYYY-MM-DD 复述"），不要新开一条。重复条目比漏记更坏——它会让人以为有两件事。
2. **原话要逐字**：他的措辞里常带着界线（"我以后"／"日后"／"这个东西蛮好的"），转述会把界线抹掉，然后某个 Agent 就照着抹掉的版本开工了。
3. **不许把想法升级成任务**：升级只能由他做（他用编号列点派活、或明说"现在做"）。Agent 可以自己做的只有"去查一下事实"这类只读研究，且查完仍记 captured。
