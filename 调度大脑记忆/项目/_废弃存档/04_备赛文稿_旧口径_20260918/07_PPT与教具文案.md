# PPT、板书与教具文案

> 原则：PPT 只做四件事——出示题目、出示环节名、呈现位置与流程、出示古语。
> 绝不把道理打在屏幕上。凡能由学生说出的，不出现在 PPT 上。

## 二、板书设计

黑板分三区，随课堂推进生长。

**左区（环节二写入）**

```
不会
回应
```

两个词之间留一段空。它们的关系不写，等学生去填。

**中区（环节四使用）**

```
我可以做          别人决定        可以找人一起想办法
─────────       ─────────       ─────────────
〔学生摆的卡片〕  〔学生摆的卡片〕 〔学生摆的卡片〕
```

**右区（环节五生成）——本课最重要的板书**

```
慢慢讲
不嘲笑
陪着他
一起想
```

> ⚠️ 右区必须是学生说出的原话。若学生说出的是别的词（"先问他哪里不会""做给他看"），照写他们的，不替换为上面这四个。

**右区下方（环节六）**

```
己所不欲，勿施于人
```

## 三、教具清单与文字

| 教具 | 数量 | 文字／样式 | 备注 |
|---|---|---|---|
| 求助卡 | 每人 1 张 | 一面空白，折成立牌；卡面只写"我需要帮助"或一个问号图形 | 立起即可，不必举手 |
| 情绪位置牌 | 3 块 | **还想继续试**／**有点不想做了**／**不太想再问了** | 贴在黑板下方同一水平线 |
| 磁扣 | 每人 1 枚 | 无文字，颜色区分即可 | 可移动，可不动 |
| 流程卡 | 每人 1 条 | 看到题 → 开始做 → 卡住 → 求助 → 听到回应 → 接着做 | 图标为主，文字为辅 |
| 小夹子 | 每人 1 枚 | 无文字 | 夹在流程卡上 |
| 分类卡 | 现场生成 6–8 张 | 取自学生原话，教师当场书写 | **不预制** |
| 区域牌 | 3 块 | 我可以做／别人决定／可以找人一起想办法 | 环节四出示 |
| 椅子 | 2 把 | 椅背贴纸：**我不会** ／ **我来帮你** | 课前朝内贴，环节五翻出 |
| 数学题单 | 每人 1 张 | 挑战题 1 道（环节一、二）；简单题 1 道（环节五） | 教师自编，非教辅 |

---

## 四、一句提醒

PPT 与教具都不承担"讲道理"的功能。本课所有值得记住的话，一半由学生说出，一半由教师在停顿后说出。屏幕越干净，学生的声音越清楚。
