# 前端 App 页面美化与视觉重设计多模型协同 SOP（2026-10-09 郭老师定）

> **核心目标**：美化 App 页面，让界面更高级、更有设计感、更像成熟商业产品。  
> **核心架构**：结合正在开发的「活体认知白板」，**把视觉设计和代码实现彻底分开**。

---

## 一、 模型推荐排名

| 优先级 | 模型 | 最适合的工作 | 官方能力背书 |
| :---: | :--- | :--- | :--- |
| **(首推)** | **Kimi K3** | **页面视觉重设计、布局、配色、动效、交互体验** | Kimi 官方 Build 工具支持根据自然语言、设计稿或截图生成网页和交互，也明确支持前端视觉设计，因此适合作为第一轮美化候选。[1][2] |
| **2** | **Step 5 Preview** | 创意型 UI、未来感界面、白板交互原型 | 阶跃星辰旗舰，探索前沿交互、时间流与白板动态原型 |
| **3** | **Gemini 3.8 Flash** | **将设计落实到现有 HTML/CSS/React 代码** | 主建造者 Builder，长效代码工程、增量合并、保持功能不崩、GitHub 提交 |
| **4** | **GLM 5.3 Flash** | **检查页面截图，找对齐、间距、视觉一致性问题** | 交付前视觉质检，对比修改前后截图，检查手机端适配与排版溢出 |
| **5** | **Qwen 3.8 Max** | 审核整体产品体验和设计方向 | 首席架构审查，高阶设计决策与规范冲突终审 |

[2]: https://www.kimi.com/code/docs/en/ "Kimi Code Overview | Kimi Code Docs"

## 三、 直接复制给 Kimi K3 的提示词

```markdown
你是一位顶级UI/UX设计师兼前端视觉工程师。

请对我现有的 App 页面进行一次专业的视觉升级。

**设计目标：**
将当前页面提升到精致、克制、具有科技感和高级产品质感的水平，参考现代高品质SaaS工作台和下一代AI应用的设计语言。

**重点优化：**

1. 页面整体布局、留白、视觉层级。
2. 字体、字号、颜色体系和卡片质感。
3. 导航栏、按钮、图标与交互反馈。
4. 柔和的微动效、自然的页面过渡。
5. 手机和电脑端的响应式适配。
6. 让主要成果成为视觉中心，减少无效装饰和信息噪声。

**严格要求：**

* 保留现有功能、数据结构和核心业务逻辑。
* 优先在现有代码上增量修改，不要随意重写整个项目。
* 不要只提供设计建议，要实际修改可用的前端代码。
* 不要为了炫酷添加影响阅读和操作的复杂动画。
* 完成后提供真实页面预览或截图，并说明主要变化。

请先分析现有页面的问题，再进行视觉优化，最后验证移动端和桌面端的实际显示效果。
```

## 四、 核心铁律（绝不可违背）

**如果你的 App 已经能正常运行，千万不要让模型“重新设计一个 App”。**

应该严格要求它：**保留功能，只升级视觉系统。**

这样才能保证你们之前做好的白板组件、GitHub 协同和交互逻辑不被推倒重来。
