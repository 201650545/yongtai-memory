# 逆天主题：这个项目的取舍口径

**仓库**：`D:\Work\逆天主题`（有 git；59 条 .md 记录，口径A 批 2026-09-29）
**外部资源底座**：飞书 Base，见 [[调度大脑记忆/参考/reference_nitian_feishu_resource_base]]

**它是什么**：一个**挂在他写代码工作流旁边的修仙世界**（DSH 插件形态），不是独立要运营的游戏。产品判据是「**我自己愿意反复使用**」，**不考虑拉新与变现**。验收只看三件事：前端能用／转发可调通／演出看得见（见 [[调度大脑记忆/反馈/feedback_judge_only_frontend]]）。

**当前三条已定的取舍（改这些要他点头）**：
1. **纵切优先**：一个境界做透（修为推进→进度窗→破境演出→解锁→回到 Coding）胜过横向铺 27 境都半吊子。A1 纵切范围＝`05_huashen → 06_yingbian`（婴变期主导）。**任何新资产/新系统的取舍问句是「它让这条纵线更沉浸吗」，不是「凑齐 27 境了吗」**；横向铺量与 27/27 已停铺。
2. **官方图优先**：有官方海报/原片图的境界一律用官方，**AI 生成只补官方缺口，不许喧宾夺主**；角色一致性用官方 figure 或 LoRA 锁脸，跨境界核心特征词固定，各境只加服饰气质增量。
3. **没有 gameplay/叙事职责的内容不铺**：不为新 UI 另开资产生产线。

**不负责什么**：本条只记**方向与已定取舍**。数值表、境界分档、四幕剧情、资产清单、当前进度一律去 Work 仓查（`docs/04-项目计划.md` 的 NOW 节、`docs/20-设计与架构/00-总体设计与架构.md`）——**在这里抄一份就等着过期**。
