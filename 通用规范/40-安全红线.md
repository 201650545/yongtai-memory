# 40 · 安全红线（跨项目通用，无例外）

1. 成品图 / 视频 / 压缩包**永不进公开仓库**——`.gitignore` 扩展名黑名单兜底（png / jpg / mp4 / webm / zip / psd / log 等）
2. 密钥 / API Key / JWT / 登录凭据**不入仓库、不入文档**；一旦出现立即轮换
3. 个人记忆同步数据（memory-sync/ 等）不入公开仓库
4. 推公开仓前必须跑**密钥扫描**（grep token / key / authorization / password / secret / eyJ…）
5. 飞书等外部平台只承载结构化数据表；管理文档一律以项目 docs/ 为准
6. **运行日志 / 回执 / 报告默认不入库**——`logs/` 进 `.gitignore`。它们是"仪表读数"不是存档，
   按保留期在磁盘自清即可（运行日志 `*.log` 14 天 / 回执报告 `*.json` 7 天 / 每日汇报 `*.md` 30 天 /
   留档说明 `*.txt` 30 天），**不进版本历史，也不打进备份包**
   （依据：`D:\Work\工具\备份\` 提交 `14f4b8d`，一次备份原本会多 4 个文件、一年上千个）
7. **运行态文件不入公开仓**——锁文件、缓存、会话快照、编辑器工作目录
   （如 `.qoder/`、`_private_bak/`）一律 `.gitignore`。
   注意：本仓 `yongtai-memory` **是 GitHub 公开仓**，当前 `.gitignore` 已覆盖 `_private_bak/` 但**未覆盖 `.qoder/`**
