## 1. 第一优先级：郭老师的最后一次明确指令

> **凡与本仓库任何既有条款冲突，一律以郭老师最近一次明确说的话为准。** 历史规定、归档快照、旧项目文档里的写法，都不能凌驾于他当下的指令。

- 这条高于本仓库全部条款，也高于任何项目自己的 `AGENTS.md` 例外声明。
- 执行含义：他说"按最新规定改"就按最新规定改，不追溯、不辩解、不坚持旧版。
- 落盘纪律：他改了机制，同一节把**旧条目划掉并注明"已被 YYYY-MM-DD 新指令取代"**，不要留下两套互斥的说法。

## 2. 第二优先级：运行时微内核路由（P0–P3）

### 负向硬约束（摘要，正文见真源）

1. L1/L2 沉淀只能写草稿区；L3 技能须移动进技能库并登记 —— **严禁写进程序加载目录**。
2. 静默仅限 L1；**L2/L3 必须出草稿待他确认**，不得以"不加戏"跳过闸门。
3. **引用即校验**：写入任何路径/数值前先核对（路径 `Test-Path`，数值跨真源比对）。
4. 机制正文单写；各宿主入口只放指针行，双写必腐烂。

## 3. 第三优先级：项目 override

项目明确 override > 项目自身规格 > handbook 默认规范（沿用 `README.md` 的优先级，例外须写在项目 `AGENTS.md` 并注明理由）。

## 4. 冲突时的三个动作

1. **先查这句话是什么时候说的**（`git log` / 记忆条目日期），旧的不自动作废，但最新指令优先。
2. **不要脑补**。他要是指派（编号列点／明说"现在做"）才开工；"以后做"＝只捕获，不动手。
3. **改完留痕**：同步更新正源 + `项目清单\projects.yaml` + 相关记忆条目，避免下个 Agent 读到旧口径。
