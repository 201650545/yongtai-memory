# Fotor Agent · 用「代码生成视频」做 MG 动画（2026-10-21）

> 原文：阿虚同学《Fotor Agent 应用"代码生成视频"技术，轻松搞定商用和自媒体 MG 动画视频》
> 链接：https://mp.weixin.qq.com/s/cuAmFkvDXMAKWWYYj7fKfA
> 官网：www.fotor.com.cn（国产，成都高新区；Fotor 全球累计 8 亿+ 用户）
> 对应想法池：[[项目/project_想法池]] IDEA-021（轻量化剪辑 → 已升级为「给 AI 用的定制化视频剪辑程序」）

## 一、核心技术判断：**代码生成 vs 扩散模型**
- 主流 AI 视频模型是扩散模型，**逐帧画像素** ⇒ 画面带**数据图表或密集文字**时，十有八九**边缘模糊、文字乱码、前后数字对不上**。
- 商业场景不能容忍：「续航 12 小时就是 12 小时，499 元就是 499 元，**一个错字在广告里可能就是事故**」。
- **Fotor Agent 不用 AI 逐帧画像素，而是让 AI 用「代码生成视频」驱动整个 MG 动画的生成** ⇒
  **图表与文字是程序排出来的，不是模型画出来的**；作者实测三四段视频**没见过一个乱码**，放大到每一笔拐角都清晰。

> ★ **这就是我们这条路的市场验证**：句读课件页 OCR→重绘（代码排版）＋ ASS 逐字字幕＋ ffmpeg 装配 ⇒ 文字天然不会乱码。
> 我们做的不是"AI 画的视频"，而是**"程序排的视频"**——与 Fotor 的技术判断完全同构。

## 二、形态标杆：**四轨工程文件 ＋ 零件级修改**
- 交付的不是视频片段，而是**整个视频项目工程文件**：**视频轨 / 音频轨 / 字幕轨 / MG 动画轨，四条轨道独立分离**。
  - 字幕换文案、BGM 换新的、转场换风格、整段画面删掉 ⇒ **直接拖拽替换、重新对齐，谁也不连累谁**。
- **零件级精准修改**：对着生成结果里的**文字、数字、字体、颜色、图表位置、折线粗细**随便改，
  **改了不重新生成、不抽卡**，除被选中元素外画面丝毫不动 ⇒「**改视频跟改一页 PPT 似的**」；
  甚至可以**用嘴（语音）做动画交互**，哪一步不满意一句话就换。
- 作者原话：看到那几条轨道整整齐齐摆着，脑子里闪过的，是无数剪辑师在 PR 里逐帧对齐的漫漫长夜。

> ★ 与 GPT-6 说的「**唯一编辑计划**（Agent 只提提案 → 后端规范化 → 预览/字幕/剪切/渲染全消费同一份）」是同一件事的**产品化形态**：
> 我们的 `project.json` 应当升级成**四轨**（视频/音频/字幕/动画），而不是现在的 clips + 字幕两条。

## 三、其它可直接借用的点
| 点 | 事实 | 对我们的意义 |
|---|---|---|
| **4K 是商用刚需** | 720P 投大屏"文字边缘全是锯齿" | 我们的教材精读片应出 4K 或至少 1080 高码率 |
| **价格锚点** | Fotor 4K MG 动画 **低至 0.5 元/秒**（一分钟约 30 元）；MiniMax H3 便宜但只 2K；Seedance/可灵 3~7 元/秒；**传统 AE 外包单分钟万元级** | 我们本地跑＝只花电；但**商业交付时 Fotor 是现成云端选项**（可作为"直接调用别人现成结果"的商业版对照） |
| **吃文档 → 全流程闭环** | Word/Excel/PPT/PDF/TXT/Markdown，甚至 **5GB 视频**；自动分析文件→写脚本→**生成分镜**→出画面→配音→配乐→上字幕→加转场，**MG 图表按时间戳排到轨道**；配音波形对字幕、转场卡 BGM 鼓点 | **"分镜大纲表"就是入口形态**（Gemini 说的 Shot List Table）⇒ 我们的"一句朗读＝一个镜头（画面/台词/配音）"就是它的中文简化版 |
| **AI 智能剪辑** | 几小时直播素材自动找高光；**自动清理「嗯、啊、那个」口水话**；多素材自动混剪 | 口水话清理 = **auto-editor 的活**（我们已装 29.3.1）⇒ 不用自己写 |
| **它的短板** | 无无限画布、无多剧集创作、无 3D 建模 | 对我们无影响（我们做单课精读/口播） |

## 四、给我们的四条硬借鉴
1. **技术路线已被商业验证**：代码生成 ⇒ 文字/图表不乱码。我们的"重绘页＋ASS 字幕＋ffmpeg 装配"是同一路线，**方向可以放心走**。
2. **中间格式要升级成四轨**（视频/音频/字幕/动画），且**各轨独立可改、互不连累**——这正是"改文字不该重渲画面"的用户可见形态。
3. **UI 应该是"零件级可改"而不是"重生成"**：改字幕只动字幕轨、改插图只动画面轨；这与 GPT-6 的"单一事实来源"、Gemini 的"卡片流"是同一件事的三种说法。
4. **可以直接调用的现成能力又多了两样**：auto-editor（切点/口水话，本机已装）＋ Fotor Agent（云端商业级 MG/4K，需要时按量调用）。
