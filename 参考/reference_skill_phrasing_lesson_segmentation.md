# reference: 句读课文双模态意群与精听时间轴统合切分 Skill

> 创建日期: 2026-10-16

---

## 1. 核心定位
本 Skill 是句读（ListenLoop / AI精听训练器）制作听读/视听课包时关于**文本切分、意群呼吸断句与 ASR 时间轴对齐**的唯一统合真源。

它整合了此前分散的语文低幼语义断句口径与算法时间戳停顿参数，避免各 Agent 在制课或审课时标准不一。

---

## 2. 核心指标与四大铁律

### 双模态字数硬指标
- **初读模态**：**4 ~ 8 字**，短呼吸节拍，适合低幼字词辨识与指读跟读；
- **熟读模态**：**6 ~ 18 字**，标准语义意群，单句超过 18~19 字必须切断，适合流畅精听。

### 四大切分铁律
1. **拆句标点留白纪律**：初读拆句时，课文原无标点处切断换行**绝对留白，严禁擅自伪造添加逗号**；
2. **跨句拼接禁令**：熟读模态中**严禁越过句号、问号、感叹号合并句子**，无论单句多短；
3. **生字识字课文排版**：必须识别全角空格 `\u3000` 并按教材语义行成行，严禁盲目合并为超长行；
4. **ASR 真戳禁均摊**：时间轴必须采用真实 ASR 切片原生时间戳，严禁按字数机械均摊；结合 gapBreakMs 1300ms 标准门限判定自然停顿与播放单元。

## 3. 自适应微调与双轨存档机制
- **自适应与自监督**：AI 执行中遇到特殊格式或排版冲突可就地更改微调；
- **存档与复原机制**：
  - 修改前必须存入 `.history/SKILL_YYYYMMDD_HHMMSS.md`；
  - **保留期限**：本地仅保留 **7 天（1 个星期）**，超期自动清理；夸克网盘增量备份保留 **30 天（1 个月）**，滚动清理；
  - 出现回退或改坏时，立即通过 `.history/` 恢复快照回滚；
  - 变更必须同步记录在 `CHANGELOG.md` 中。
