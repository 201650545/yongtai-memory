## 1. 核心定位
本 Skill 是晨读（ListenLoop / AI精听训练器）制作听读/视听课包时关于**文本切分、意群呼吸断句与 ASR 时间轴对齐**的唯一统合真源。

它整合了此前分散的语文低幼语义断句口径与算法时间戳停顿参数，避免各 Agent 在制课或审课时标准不一。

## 2. 核心指标与四大铁律

> ⚠️ **2026-11-05 修订：本页 §2 的"字数硬指标"已废止。** 现行唯一判据是 **切分规则 v4/v5**（`D:\listenloop\scratch\切分案例\_规则归纳_v4.md`）：词界 > 语义完整 > 呼吸 > 字数，字数只做事后校验；gatekeeper 不再按字数判 REJECT，完整短句允许任意短。
> 4–6 年级格长（中位 / 软上限 / 例外上限按年级递进）见 `D:\listenloop\docs\四至六年级切分规则_20261105.md`；初读**参考**区间仍约 5~7 字，但不是门禁。

### 四大切分铁律（仍有效，细节以 v4 为准）
1. **拆句标点留白纪律**：课文原无标点处切断换行**绝对留白，严禁擅自伪造添加逗号**（对应 v4 P1 禁冒号后下刀、假逗号禁令）；
2. **跨句拼接禁令**：熟读模态**严禁越过句号、问号、感叹号合并句子**（原文标点允许，v4 允许句内收尾；改判以 v4 为准）；
3. **生字识字课文排版**：必须识别全角空格 `\u3000` 并按教材语义行成行，严禁盲目合并为超长行；
4. **ASR 真戳禁均摊**：时间轴必须采用真实 ASR 切片原生时间戳，严禁按字数机械均摊；结合 gapBreakMs 1300ms 标准门限判定自然停顿与播放单元。

## 3. 自适应微调与双轨存档机制
- **自适应与自监督**：AI 执行中遇到特殊格式或排版冲突可就地更改微调；
- **存档与复原机制**：
  - 修改前必须存入 `.history/SKILL_YYYYMMDD_HHMMSS.md`；
  - **保留期限**：本地仅保留 **7 天（1 个星期）**，超期自动清理；夸克网盘增量备份保留 **30 天（1 个月）**，滚动清理；
  - 出现回退或改坏时，立即通过 `.history/` 恢复快照回滚；
  - 变更必须同步记录在 `CHANGELOG.md` 中。
