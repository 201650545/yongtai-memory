### 每关的操作要点

**⑩ 分类关** — 四类各是什么（依据 `user_接收偏好_本质级文本.md:50`）：
- **结论**：一件事的最终判断，脱离当次过程也成立。
- **机制**：为什么会这样、能迁到别处的规律。
- **偏好**：他要什么、他不要什么、他怎么拍板（归 `user/`）。
- **待决项**：还没定的、等着他拍板的（**带"待郭老师定"标记**）。
- ⛔ 不属于这四类的典型：过程流水、一次性数字、通道健康快照、子代理自测样本 → **不进**。

**① 过时检验** — 问自己两句：
- 「这个数/这个状态，明天还会一样吗？」（一次性数字 ⇒ 过时）
- 「它描述的是哪一天的事实？」（`D:\记忆\教训\lesson_命名纪律_前缀即归属且批量替换须排除存档.md:42` 的口径：「**这句话描述的是哪个时刻的事实？**」）

**② 复现检验** — 把候选的结论遮住出处，问："只看这一条，我能不能复现出这个答案、并知道它管用在哪？"
- 不能（只有"当时是这样"）⇒ 不进。
- 能 ⇒ 继续。

**③ 重复检验** — 检索既有条目，**先查再写**（`D:\记忆\AGENTS.md` 写入纪律第 4 条：写之前先 grep 现有条目，避免重复）。
- 查法：`D:\记忆\q.cmd "关键词"`（跨库加 `--work "D:\Work"`），或 `query_evidence.py`。
- 命中既有条目 ⇒ **不新建**，改成：① 并入既有条目的变更层；② 或在新条目里放**指针**指向它。

**④ 冲突检验** — 与既有条目矛盾 ⇒ **不要自己拍板**，走 §4。

**⑤ 格式检验** — 硬字段（缺一不可）：`name` / `description` / `type` / `updated`（`README.md:70`）；
`type` 只能取：`project / workflow / lesson / feedback / user / reference / rule / entry / memory / broadcast / explainer / routing`（`README.md:73`）。
- 可选但推荐的软字段：`status`（`active` / `superseded`）、`superseded_by`、`kind`（现有条目在用，见 `D:\记忆\通用规范\80-引用校验与证据纪律.md:4-6`）。

## §4 冲突与单写真源

### 总原则

**同一事实只在一处写，别处放指针**（`D:\记忆\README.md:72`）。
出现"文档写了、盘上不是"或"同一事实两处说法互斥"，最常见的两个病根是：**① 悬空指针 ② 双真源分叉**（`D:\记忆\通用规范\80-引用校验与证据纪律.md:36`）——修法都是**先定唯一真源，其余改成指针**。

### 与既有条目矛盾时怎么办（顺序固定）

1. **先核事实**，不先辩论谁对 —— 路径 `Test-Path`、数值与真源比对、计数现跑（`80-引用校验与证据纪律.md:15-19`）。
2. **核出真源是谁**（哪一处是最新、哪一处已废）——路径变更过的，按"这句话描述的是哪个时刻的事实"判（`lesson_命名纪律…:42`）。
3. **不直接改正文**。两条路径二选一：
   - **旧条目被取代** ⇒ 走技术例外：旧条目 front-matter 置 `status: superseded` + `superseded_by` 指向新条目，**正文一个字不动**，同时须追加 `（AI 提交 N：本结论已被 <新条目> 取代）`（`D:\记忆\AGENTS.md:32`）。
   - **两条都还成立，只是粒度不同** ⇒ 不删不改，在更细的那条加指针。
4. **判据之间本身冲突**（例如本草案 §5 的投递规范 与 `D:\记忆\_inbox\README.md` 的既有规范不一致）⇒ **不自行发明**，列入 §7 待郭老师定。

### 同一事实不建第二份

- 检索先行：`D:\记忆\q.cmd "关键词"`（`D:\记忆\AGENTS.md:16-19`）。
- 命中即并入，不新建。
- **本次投递清单里已有 2 条命中**：A1 的"AI 负责视觉、代码负责信息"（真源 `D:\记忆\参考\reference_presentation_system_spec.md:114`）、A5（应并入 `D:\记忆\项目\project_经纬.md`）。

### 5.2 三件套各自必须写什么

| 文件 | 必须包含 | 缺了会怎样 |

### 5.3 自包含

投递内容**要自包含：写清来源、时间、任务名、结论，方便整理会话判断去向**（`D:\记忆\_inbox\README.md:28`）。
⇒ 判据：**记忆侧读完这三个文件，不回读投递方会话、不回跑命令，也能作出"进/不进"的判定**。做不到就补文件。

### 5.4 只允许追加

- 在**本次任务自己的子目录**里新建文件或追加内容；不修改、不删除、不覆盖已有文件；不进入别的任务的 `_inbox` 子目录；不重命名、不移动已投递的文件（`D:\记忆\_inbox\README.md:24-26`）。
- **禁止直写 vault 正式目录**：`参考/`、`项目/`、`索引.md` 及其它正式目录一律不碰（`D:\记忆\_inbox\README.md:27`）。
- **`索引.md` 是生成物、禁手改**（`D:\记忆\AGENTS.md:25`）。
