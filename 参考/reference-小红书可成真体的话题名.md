# 小红书"真体话题"白名单（2026-10-21 实测）

## 判据（现场探针实测，非推测）

话题要成为**真体**（正文里带 `[话题]` 标记、能被点成话题卡），前提是：
**插入话题名后，下拉候选里出现"多条"**（>1 行，带浏览量/热度）。
只有 **1 行裸文本**（就是你刚输入的那个词）⇒ **站内没有这个词条** ⇒ Enter 也不会接受 ⇒ 退化成死文本。

**实测读数对照**（`cand` = 下拉候选行数，`mark` = 正文是否出现 `[话题]`）：

| 话题名 | cand | mark | 结论 |
| :--- | ---: | :--- | :--- |
| 中考英语语法专项训练 | 57 | true | ✅ 站内有 |
| 中考词汇篇章式记忆 | 11 | true | ✅ |
| 英语 / 英语学习 / 初中英语 / 中考 | 100+ | true | ✅ |
| 英语单词 / 中考英语 / 湖南中考 / 湖南中考英语 | 100+ | true | ✅ |
| 英语听力 / 英语作文 / 语法 / 词汇 / 背单词 / 单词记忆 / 英语语法 | 15–115 | true | ✅ |

> ⚠️ **长度不是规律**：`英语`（2 字）能成，`湖南中考英语历年真题试卷`（12 字）不能。
> **规律是"站内有没有这个词条"**。

## 平台机制（探针实测）

1. **真体候选的 DOM 里没有 `[话题]` 字样** —— 长得跟纯文本一样，只是多一行"12浏览"。
   ⇒ **不能靠 DOM 文本判断谁是真体**。
2. **"点候选项"不会变真体** —— 点了只是把文本替换成同样文字，**正文不会出现 `[话题]`**。
3. **真正生效的是"合成 keydown Enter"** —— 走下拉高亮项，Enter 后正文变成 `#话题名[话题]#`。
4. 候选是**异步加载**的 ⇒ 刚 keyup 就查会看到"只有裸行"，得**轮询等**。
5. `visibility: hidden` 时下拉只出裸行；`tab select` 改不了 visibility。
   ⚠️ 但实测 **hidden 状态下照样能成真体**（只要站内有词条）⇒ **visibility 不是决定因素，站内词条才是**。

## 怎么用

发布前**查这张表**选话题，别临时拍脑袋。
选了表外的名字 ⇒ 会静默退化成纯文本（`topicMark:false`）⇒ **必须回读校验**。
