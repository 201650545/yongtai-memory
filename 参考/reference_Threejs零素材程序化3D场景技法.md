## 一、核心技术原理与优势

传统 3D 场景依赖动辄几十兆的 `.gltf` / `.fbx` 模型、高分辨率贴图及外部 CDN，存在依赖多、体积大、加载慢、离线无法运行的问题。  
**程序化 3D 场景（Procedural 3D Scene）** 采用纯数学逻辑动态生成：

1. **数学噪声地形（Simplex Noise + FBM）**：
   - 使用分形布朗运动（FBM，4~5 个 Octaves）叠加多频 Simplex 噪声，实时计算顶点高程 $y = f(x, z)$。
   - 形成自然起伏的山脊、山谷、缓坡，不依赖任何高度图（Heightmap）。
2. **程序化河流下切（River Carving）**：
   - 用正弦波路径判定河流轨迹：$z_{river} = \sin(x \cdot freq) \cdot amp$。
   - 当地形网格顶点接近河流中心线时，动态平滑下凹，并在上方覆盖半透明水面网格；水面顶点随时间走波动函数实现流动波浪。
3. **程序化植被与生态（Instanced / Cloned Geometry）**：
   - 树干采用圆柱体（CylinderGeometry），树冠采用圆锥体（ConeGeometry），以低面数（Low-Poly）平滑阴影呈现。
   - 沿地形高程过滤（水线以上、雪线以下）批量散布。
4. **低面数动态生物（Low-poly Fauna）**：
   - 极简几何多边形构成飞鸟，在动画循环中沿正弦曲线煽动双翼并在空域巡航。
5. **昼夜环境光影（Lighting & Atmospherics）**：
   - 平行光模拟太阳/月光，半球光（HemisphereLight）模拟天空与地面漫反射，配合指数级雾气（`THREE.FogExp2`）营造空间景深。
6. **零外部素材、完全离线**：
   - 仅依赖本地单一 `three.min.js`（约 600KB），无需联网，无第三方图片，单文件 HTML 自包含，全平台 60 FPS 流畅运行。

## 二、AI 课件与展示设计选型决策模型（何时用 / 何时不用）

AI 助手在构思教案课件、交互展示或情境网页时，**严禁生硬套用（不是每页都要 3D），也绝不完全遗忘**，应按以下策略做决策：

### 1. 强烈建议运用的场景（✅ 推荐）
* **大单元 / 课程情境导入（Opening Hook）**：
  - 语文/文史/哲理类课文开场（如《小石潭记》《登鹳雀楼》《坐井观天》《不会的时候》等需要辽阔意境或探索心境时）。
  - 用缓慢巡航的自然山川日落/清晨作为全屏背景，中央浮现单句主题大字，营造沉浸感与庄严感。
* **地理、科学、生态环境探索**：
  - 演示地貌起伏、河流冲刷、植被分布、昼夜交替等自然规律。
* **抽象哲学 / 心理意象表达**：
  - 表达“翻过困难之山”、“心境从阴霾走向日出”、“静水流深”等心理引导或哲理收束页面。

### 2. 坚决禁止运用的场景（❌ 禁用）
* **高密度交互题 / 词汇语法操练页**：
  - 如英语选择题、填空、拖拽分类、拼写。3D 运动背景会极大分散学生注意力和教师投屏清晰度。
* **多页快速切换课件（40 页密集刷题）**：
  - 易占用额外 GPU 资源，在低配教室一体机上可能导致卡顿。
* **纯白板 / 留白生成式板书页**：
  - 课堂生成性讨论需要极简纯白/纯浅底，背景不宜有动态光影干扰。

## 三、调参速查表（AI 快速定制场景）

在复用 `procedural-3d-scene` 模板时，AI 可按需求修改关键参数：

| 场景需求 | 关键调整参数 | 建议设置 |
| :--- | :--- | :--- |
| **宏伟高原 / 崇山峻岭** | `noiseScale`, `heightScale` | `noiseScale: 0.015`, `heightScale: 70`, `octaves: 5` |
| **江南水乡 / 平缓丘陵** | `noiseScale`, `heightScale`, `riverWidth` | `noiseScale: 0.008`, `heightScale: 20`, `riverWidth: 16` |
| **日落 / 晚霞意境** | 光照预设 `setTimePreset('sunset')` | 暖橙金光，天空粉紫，长投影 |
| **静谧夜晚 / 星空冥想** | 光照预设 `setTimePreset('night')` | 深蓝深紫雾气，冷蓝月光，低环境光 |
| **明朗清晨 / 活力开朗** | 光照预设 `setTimePreset('noon')` | 清透蔚蓝，高明度日光，高饱和绿树草地 |
| **宁静缓动（课件开场）** | 巡航速度 `controls.autoRotateSpeed` | `0.3 ~ 0.5`（缓慢平滑旋转，不抢焦点） |
