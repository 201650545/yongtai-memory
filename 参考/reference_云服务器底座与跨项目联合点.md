## 一、一句话架构（09-29 已定型）

| 位置 | 角色 | 上面跑什么 |
|---|---|---|
| **本地 PC**（7×24 插电联网） | 算力主场 | Agent 流水线、采集、computer_use、一切重活 |
| **阿里 99 ECS**（2C2G/3M 固定带宽） | 公网门面 | **frps 中转 ＋ `:3100` 网关 ＋ Uptime Kuma** |
| **腾讯轻量 Hermes**（2核2G/50G 北京） | 试验田/staging | **2026-10-29 到期**；**2026-10-20 已决定：放掉，让它自然到期，不续不换** |

**核心逻辑**：家宽没公网入口 → 手机跨不了局域网直连电脑 → 云上只留轻量转发，重活全在本地。
IP 地址不入本库（这仓是 GitHub 发布镜像 `yongtai-memory`），要 IP 去看真源 §1。

## 二、"服务器够不够"——已有实测结论，别重新纠结

- **够，而且严重过剩**：09-29 实测阿里 99 **load 0.00、内存仅用 23%**，转发型负载用不满。
- 当日裁定：**「云端算力购买话题关闭，现在不买任何服务器」**。
- 腾讯 4核4G 109/年 的定位＝**消耗品**（新客首年价、次年跳千元级、**活动截止 2026-10-12**），不是资产款。
- 唯一对标"阿里 99 锁价逻辑"的资产款＝**华为云 Flexus 2C2G/4M 98/年续费同价**；京东云 2C4G/5M 558元/3年＝中期最优。
- **真瓶颈是带宽不是算力**：阿里 3Mbps 固定带宽（好在流量不限量、永不产生流量费）；腾讯轻量是月流量包 300GB、只算出方向、超 0.8/GB、欠费 2 小时停机。

### 四条加购触发条件（出现任一再掏钱，09-29 定）
1. 本地需长期托管 7×24 流水线 → **已由"电脑可常开"解决**
2. 云端编译/构建 OOM（2G 内存干不了的活）
3. 需要多开云端沙箱
4. 实测内存 **available < 200MB**

⇒ Agent 判"要不要买机器"时**只认这四条**，别拿"感觉不够用"当理由。

### 2026-10-20 复核：仍然一条都不满足 ⇒ 不买

- 四条逐条对过：**第 1 条已由"电脑可常开"解决；第 2 条不成立（重活在本地，云端不该编译）；
  第 3 条无此需求；第 4 条不成立（阿里 99 实测 load 0.00、内存只用 23%）**。
- 腾讯 4核4G 109/年 的活动**已于 2026-10-12 截止**（今日 10-20 已过期）；即便再来一轮，
  也是新客首年价、次年跳千元级＝消耗品。
- 阿里 99 的 99 元资格**绑死那一台实例**（同名实名的优惠不能挪到别的 ECS，同实名限 1 台），
  ⇒ 以后加机器别想着把 99 的优惠挪过去。
- **郭老师 2026-10-20 当面拍板**：
  ①**腾讯轻量 Hermes 放掉，让它 10-29 自然到期，不续不换**；
  ②**新机器一台都不买**；
  ③钱该花在**把本地 PC 加固成可靠算力主场**上（详见 §5）。
- 实况（2026-10-20 探测）：阿里 99 的 `3100` 与 `22` 端口通；腾讯 Hermes `22` 端口通（两台都活着）。
  ⚠️ 本机 ssh 密钥登不进 Hermes（root/ubuntu/lighthouse 均被拒），**它台上跑着什么查不到**，
  需要在腾讯控制台看。
