# 本周点赞可落地清单（2026-11-04）

> 来源：`D:\Work\小红书点赞分析\本周点赞分析_20261104.md`（16 条点赞，点点解析）。

## 一、工具类

### 1. Filee（格式转换，P0）
- **学什么**：`KnifeLemon/Filee`——按住 Ctrl 拖文件进窗口，弹格式圆环；255 种格式 / 18 大类，本地离线转换。
- **怎么用在我们身上**：替换在线转换器和会员工具；课件素材（音频/图片/视频）批量转码走它。
- **第一步**：从 GitHub Releases 装 Windows 版，跑一次 mp3→wav、png→webp 验证。
- **归属**：D:\Work（课件与练习生产工具链）
- **状态**：❌ **已废弃（dropped，2026-11-05 郭老师裁定）**：纯鼠标桌面 GUI 工具，无代码与 Agent API，日常批量转码全走 Python / `ffmpeg` / `Pillow` 脚本处理，无需安装多余套壳软件。

### 2. DSH billion-context（上下文压缩，P0）
- **学什么**：`ranxianglei/billion-context` 等 DSH 六件套里的上下文压缩插件。
- **怎么用**：本机长任务/长会话上下文吃紧，先只装这一个，其余按需。
- **第一步**：查 DSH 插件安装方式，装 `billion-context`，开一个新会话验证压缩后仍能续接。
- **归属**：D:\Work（元智能 AI自成长引擎 工具链）
- **状态**：✅ **已落地（2026-11-05）**：纯 JS 运行时零模型开销；通过 `dsh plugin --profile desktop add billion-context` 成功挂载 DSH bundle，对齐 `compaction-basic: { auto: false }`；全局 `bili doctor` 诊断全绿。

### 3. Breeze TTS 2（情绪标签 + 4 秒克隆，P1）
- **学什么**：台词里插"笑/叹气/停顿"等标签控制演技；4 秒样本克隆声线。
- **怎么用**：课件角色朗读先走情绪标签（不必克隆）；克隆需 12GB 显存、限非商用，先小样验证授权边界。
- **第一步**：用 1 段 30 字台词 + 3 个情绪标签做对照试听。
- **归属**：D:\Work（教案与课件设计 / 晨读音频）
- **状态**：❌ **已废弃（dropped，2026-11-05 郭老师明确否决）**：官方推荐 GPU 显存 ≥12GB，整机硬件无法承担；开源权重限非商用；本机已有成熟零开销 edge-tts，完全满足课件配音需求，坚决不搞沉重离线模型，直接废弃平账。

### 4. HTML-in-Canvas（可交互 3D 展示，P1）
- **学什么**：Google HTML-in-Canvas API 把 DOM 画进 canvas，配 3D 场景；Shopify 有可体验样板。
- **怎么用**：抽成"课件/产品封面 3D 展示"模板，前端技能里当片头或演示页。
- **第一步**：打开样板，Shift+~ 体验后判断能否套到课件封面。
- **归属**：D:\Work（课件与练习生产）
- **状态**：✅ **已落地原型与技能库（done，2026-11-05）**：彻底规避实验性 Flag 门槛，生产级实现纯 CSS 3D 自包含单文件模板 `D:\Work\教案与课件设计\06_课件制作\html_in_3d_cards_demo.html`（22KB）；固化为技能库 `html-in-3d-cards` 并已在 `能力总账` 完成双注册。

### 5. Three.js 程序化场景（零素材 3D，P1）
- **学什么**：codex 生成 Three.js + 噪声函数，单文件 HTML 出田野/河流/动物动画。
- **怎么用**：课件片头、视频转场用代码生成场景，产出单文件可直接嵌。
- **第一步**：复现一个最小场景（地面 + 河流 + 相机缓动），存为模板。
- **归属**：D:\Work（课件与练习生产）
- **状态**：✅ **已落地原型（2026-11-05）**：模板产出至 `D:\Work\教案与课件设计\06_课件制作\threejs_procedural_landscape_demo.html`（19KB）+ 本地 `three.min.js`，纯代码数学生成地形、河流与飞鸟，零外部素材，离线秒开。

### 6. Claude Team for Scientists（免费席位，P1）
- **学什么**：高校 PI 身份申请，Standard 席位免费、Premium 180 刀/年，额度为普通版 5 倍。
- **怎么用**：作为备用额度池，缓解长文写作/审校额度。
- **第一步**：以郭老师学校身份核对官方申请页的资格与条款（**本轮未核，条款以官网为准**）。
- **归属**：D:\记忆（长期资源与账号事实）
- **状态**：❌ **已废弃（dropped，2026-11-05 郭老师明确否决）**：郭老师确认无高校科研 PI 身份，主体资质不符，直接平账闭环。
