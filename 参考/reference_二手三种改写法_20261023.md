# 追加：二手三种改写法

## 一句话结论

二道贩子的改写有三种形态，不止"写错"。

## 三行表

| 改写形态 | 案例 | 事实 |
| --- | --- | --- |
| ① 推论→结论 | 2026-10-21 MemT（「赛博禅心」二手解读） | 论文原话只是"内化检索到的程序性经验后 agentic 成功率提升"，二手解读把它写成结论"模型能自己得出第 4 条" |
| ② 自测→论文 | 2026-10-23 VisionHOPE（机器之心） | 把官方 README 表的 Top-1 85.2 当作论文成绩；arXiv 摘要只写 "competitive" 未给数值，HF 模型卡未写数值 |
| ③ 转述→原话 | 2026-10-23 3Blue1Brown 一篇 | 由量子位转述 Grant Sanderson，尚未溯源 |

## 判据升级（可直接执行的四字段）

溯源时每个数值必须标注发布主体，取值 ∈ {论文摘要 / 官方README自测 / 模型卡 / 第三方复现}；跨级搬运视为二手错误。
