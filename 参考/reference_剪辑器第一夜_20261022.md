## 一、一句话结论

**今天把 AI 自动剪辑器从"能渲出一条片"推进到"AI 自己下决策、人只标错处"的可用闭环：七轨工程 + 15 个 MCP 工具 + 同步/异步 HTTP 接口 + 两层出片全部跑通，AI 粗剪把 181.7 秒音频剪成 39 秒（17 段、剪掉 31.9 秒），出片实测 29.2 秒片用 27.67 秒。**

## 二、产品定位（本轮最关键的认知修正）

- **这个剪辑器的使用者不是人，是 AI；人只看结果。**
- **人的唯一动作**：看片时标出"哪里不对"，标注存进工程，供 AI 下一轮读取。
- **形态**：浏览器界面 + 本地 Python 服务；不是 PR 那种拖拽时间线。
- **由此推出的设计纪律**：任何"让人在时间线上拖素材、拖轨道、调参数"的界面设计都是走错方向；界面只需要三件事——看片、标注、看 AI 的决策。
- **为什么今天算"第一夜"**：AI 侧（MCP 工具集 + HTTP 接口 + 工程格式）与人工侧（审片标注 + 决策色带）第一次接在同一个工程文件上，而不是像前几天那样"AI 出计划、人另开一条路看"。

## 三、已完成能力清单

### 数据层

- **七轨工程文件**：一次落盘，字段含 clips / cues / tokens / decisions / assets / visual / audio / text / transitions / source / canvas，后续所有环节读同一份。
- **时间域换算**：源时间轴与裁剪后时间轴之间的换算统一收在数据层，不让各环节各算一套。

### AI 入口

- **MCP 工具集 15 个**：覆盖工程读写、决策生成、渲染调度，AI 直接以工具调用驱动整条链路。
- **HTTP 接口**：`autoedit` 同步返回；`render` 异步——202 受理、409 冲突、可 cancel 取消。

### 渲染

- **两层出片**：base 层（底片）与 overlay 层（叠加层）分别渲染再合成。
- **转场**：实现了简化版 fade，不是真正的交叉溶解。
- **多画幅**：同一份工程支持多种画幅输出。

### 人工侧

- **审片标注**：人在看片时标出"哪里不对"，标注落进工程。
- **决策色带可视化**：把 AI 的剪辑决策画成色带，一眼看出 AI 在哪切、怎么切。
- **工程热重载**：工程文件改了，界面不用重启就加载新版本。

- **素材导入**：外部素材纳入工程，成为 assets 的一部分。
- **批量队列**：多篇成片排队出片。

### 质量保障

- **e2e 6 段**端到端全过。
- **成片图像自检**：出片后对成片抽帧做图像检查，不以"接口返回 ok"当验收。

## 五、踩到的坑（现象 → 根因 → 解法）

1. **PATH 上的 ffmpeg 是阉割版**
   - 现象：`ffmpeg` 能被找到、能跑起来，但一用 `drawtext` / `silencedetect` 就失败，退出信息不显眼。
   - 根因：PATH 上那份是精简构建，缺这两个滤镜；"被找到"只说明文件存在，不等于"能用"。
   - 解法：定位阶段不只探存在性，必须实跑一次 `-filters` 验能力，缺能力的候选直接排除。

2. **faster-whisper 的 small 模型缓存残缺**
   - 现象：加载 small 模型时资源不完整、跑不起来。
   - 根因：本地缓存里的 small 模型文件是残的，缓存中完整可用的只有 tiny。
   - 解法：只用 tiny，并强制 `local_files_only=True`，绝不触网下载。

3. **silencedetect 边界比真实语音晚 0.1~0.4 秒**
   - 现象：按静音边界切掉后，开头/结尾的字被吞掉。
   - 根因：silencedetect 判定的静音区间边界比真实语音晚 0.1~0.4 秒。
   - 解法：不要"整段保护"，改为"挖去词占用部分"——按词的实际占用时间从静音区间里减掉，只保词本身。

4. **ffmpeg fade 滤镜有状态**
   - 现象：接缝之后整段变全黑。
   - 根因：fade 滤镜是带状态的，不加时间窗约束时它的状态会延续到后面的片段。
   - 解法：必须加 `enable='between(t,st,st+d)'` 把效果钉死在自己的时间窗里。

5. **/media 不支持 HTTP Range**
   - 现象：浏览器判定媒体不可 seek，给 `currentTime` 赋值被回退到 0。
   - 根因：静态服务没实现 HTTP Range，浏览器认为媒体只能整段下载、不能拖动定位。
   - 解法：/media 必须支持 Range（正确回 206 与 Content-Range），否则拖动定位不可用。

6. **http.server 里错误抛在 `_mutate` 之外**
   - 现象：客户端只拿到 `RemoteDisconnected`，本该回的 400 丢了。
   - 根因：异常在 `_mutate` 之外抛出，handler 直接断连接，错误响应没有机会发出去。
   - 解法：把校验与变更逻辑包进 `_mutate`，让错误在还能构造响应的地方被捕获并返回对应状态码。

7. **并行 agent 共用同一个 `_selftest_tmp` 目录**
   - 现象：并行跑自检时产物互相丢失，结果不可信。
   - 根因：多个 agent 共用同一个临时目录，各自清理、覆盖彼此的产物。
   - 解法：按任务分子目录隔离临时产物。

8. **overlay 层只在有 audio 轨时才 map 音频**
   - 现象：没有 audio 轨的工程出片时原声丢失。
   - 根因：overlay 层的音频映射条件写成"有 audio 轨才 map"，没轨时走了另一条丢音的分支。
   - 解法：改成 copy / mix / none 三态，由工程显式选择音频处理方式。

9. **decisions 在源时间轴、cues/tokens 在裁剪后时间轴**
   - 现象：按旧契约读会对不上。
   - 根因：旧契约描述是错的——decisions 记的是源时间轴坐标，cues/tokens 记的是裁剪后时间轴坐标。
   - 解法：按实际坐标读，契约里的旧描述本轮已改正。
